# TADA! — Demo ghi nhận đồng đội

Bản demo tương tác dành cho **Lê Minh Diệu Phương**. Giao diện luôn sáng, không đổi theo giao diện tối của thiết bị.

`index.html` là bản ứng dụng đầy đủ, tự chứa CSS, JavaScript và hình minh họa. Không cần bước build.

## GitHub Pages

Trong Settings → Pages, chọn **Deploy from a branch**, nhánh **gh-pages**, thư mục **/ (root)**, rồi Save.

## Phạm vi

Dữ liệu giả lập và localStorage trên từng trình duyệt; chưa có đăng nhập công ty, backend, quyền riêng tư phía máy chủ hay đổi quà thật. Đây không phải dữ liệu nhân sự thật.

Bản cập nhật: 1.0.1. Đã kiểm tra 28 trường hợp bố cục và giao diện sáng khi thiết bị chọn dark mode. Nhánh main của repository được giữ nguyên.
